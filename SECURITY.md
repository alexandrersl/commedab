# Sécurité

Si vous découvrez une vulnérabilité dans Commedab, merci de ne pas ouvrir
d'issue publique. Envoyez un e-mail à l'auteur (adresse sur le profil GitHub
du dépôt) avec une description et, si possible, les étapes pour reproduire.

Vous recevrez une réponse sous sept jours. Les signalements sont traités avant
toute autre tâche, et crédités dans les notes de version si vous le souhaitez.

Périmètre : l'application, le schéma et les politiques Supabase, les règles de
synchronisation PowerSync contenus dans ce dépôt. Les services tiers
(Supabase, PowerSync, Sentry) ont leurs propres programmes.
