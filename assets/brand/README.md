# Logo Commedab

Le signe : un C et une coche tracés d'un seul geste, doublés d'un second trait (l'« idem », 〃).
Dans les icônes, le signe occupe 68 % de la largeur.

## Couleurs

| Contexte    | Fond      | Signe     | Second trait |
| ----------- | --------- | --------- | ------------ |
| Principal   | `#0E5B46` | `#F3EDE3` | `#F28A72`    |
| Fond clair  | `#F3EDE3` | `#0E5B46` | `#AC3E29`    |
| Mode sombre | `#181410` | `#5FC79C` | `#F28A72`    |
| Monochrome  | `#241F1A` | `#F3EDE3` | `#F3EDE3`    |

## Fichiers

- `svg/mark*.svg` : le signe seul, sans fond (`mark-mono.svg` suit `currentColor`).
- `svg/icon*.svg`, `png/icon-*-1024.png` : icônes carrées plein cadre (iOS arrondit lui-même).
- `png/pwa-192.png`, `pwa-512.png`, `pwa-maskable-512.png` : manifeste PWA.
- `png/apple-touch-icon-180.png` : écran d'accueil iOS en PWA.
- `png/adaptive-foreground-1024.png` : icône adaptative Android, fond `#0E5B46`.
- `png/splash-icon-1024.png` : écran de lancement, à poser sur `#F3EDE3`.
- `favicon.ico`, `svg/favicon.svg`, `png/favicon-*.png` : favicon (trait épaissi à 32 et 16 px).
